# Le Cinéma du Petit Village

## Présentation

le Cinéma du Petit Village est un projet web permettant de rechercher des films et de consulter leurs informations détaillées grâce à l’API OMDb.

## Fonctionnalités

 Affichage de films tendances sur la page d’accueil.
 Recherche de films.
 Consultation des détails d’un film.
 Navigation entre les différentes pages du site.

## Technologies utilisées

HTML5
CSS3
JavaScript
API OMDb
Git et GitHub

Lancement du projet

Ouvrir le dossier du projet dans Visual Studio Code et lancer index.html avec l’extension Live Server.
